THE PROBLEM

Compact makes privacy possible.
Schema drift can still surprise a team.

01 / CHANGE

A field is added or changed

A contract edit or compiler upgrade can alter the public ledger layout without an obvious signal in a routine source review.

02 / IMPACT

Public state affects people

An unexpected field can reveal more application state than intended or break clients that rely on the old schema.

03 / REVIEW

Teams need a concrete diff

Reviewers need to see exactly what the compiler will expose, compare it to an approved policy, and stop an unreviewed change.

Built for: Compact contract authors, protocol teams, and reviewers who want public-ledger changes visible in local checks and pull requests.

THE PRODUCT

From source change to review decision.

One compiler-backed path gives a developer a reproducible result before merge.

01

Choose source and policy

Use the hosted examples or provide a Compact file and its reviewed JSON policy.

02

Compile with Compact

The pinned compiler produces contract metadata from the actual Compact source.

03

Compare public fields

The gate checks ledger names, indices, exports, storage, types, and compiler/toolchain versions against policy.

04

Review the outcome

Matching policy passes. An unapproved change blocks. A compiler error stays a compiler error, not a policy result.

UNDER THE HOOD

Small surface area. Inspectable decisions.

Compact integration

CLI 0.5.1 and compiler 0.31.1 are pinned. The gate reads compiler-generated contract-info.json.

Policy is explicit

Expected ledger fields and toolchain versions are reviewed and versioned with the contract source.

CI can stop a merge

The same comparison is available through the CLI and exits nonzero for a blocked schema change.

Hosted demo has limits

Uploads are temporary and bounded. Render runs the compiler as an unprivileged service subprocess, so use samples or non-sensitive source only.

i

Trust boundary: This is an off-chain developer tool. The hosted demo does not ask for a wallet, send a transaction, deploy contracts, or inspect private witnesses. A pass is not a privacy guarantee, security audit, or production approval.
