A SMALL GATE WITH A CLEAR JOB

From source change
to informed review.

Schema drift can change what a contract exposes. This tool gives teams a repeatable way to see the compiled public ledger and compare it with a policy they have reviewed.

01

Compile the contract

The gate runs your configured Compact compiler on the source you choose.

02

Read actual metadata

It parses compiler-generated contract information and records source and metadata hashes.

03

Compare and decide

Unapproved, changed, removed, or toolchain-drifted fields are shown for human review.

COMPACT MECHANISM EXAMPLE

Private input.
Publicly verifiable result.

The included contract keeps a 32-byte witness in local private state, checks its commitment in a Compact circuit, and increments a public counter only when the witness is valid.

01

Compile the real source

contracts/private-access-counter.compact compiles to the generated module and ZK assets.

02

Run both witness paths

The runtime harness checks that a valid witness changes public state and an invalid one is rejected.

03

Review what is public

The gate compares the compiler's actual counter and secret_hash fields with a policy reviewed from emitted metadata.

i

Status: implementation added; WSL compile and runtime still required. For the local runtime check, run npm run contract:demo. For a real isolated local-devnet transaction, run npm run devnet:up, open /app, then use Deploy and verify locally. This is not a public network transaction or a production authorization design. Never enter a real password; the demonstration generates a random secret.

i

A focused review tool, not a privacy certificate. A matching ledger policy does not prove contract logic is safe, establish every privacy property, or assess transaction metadata. Keep reviewing the complete contract and its behavior.
